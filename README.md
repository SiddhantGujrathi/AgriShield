# AgriShield
CNN-based grape leaf disease detection system that classifies leaves into Black Rot, Esca (Black Measles), Leaf Blight, and Healthy. The model uses Softmax to output class probabilities and selects the highest one as prediction. Exported to TensorFlow Lite (TFLite) for lightweight, cross-platform use.


# 🍇 Grape Leaf Disease Detection using CNN

This project uses a Convolutional Neural Network (CNN) to detect grape leaf diseases from images. The model outputs class-wise probabilities using Softmax and is exported to TensorFlow Lite (TFLite) for lightweight, cross-platform deployment.

---

## 🦠 Disease Classes
- Black_rot  
- Black_Measles  
- Isariopsis_Leaf_Spot
- Healthy  

---

## 🚀 Features
- CNN-based image classification  
- Image preprocessing (resizing & normalization)  
- Softmax-based probability output  
- Highest probability selected as final prediction  
- TFLite model for mobile and edge deployment  

---

## 🛠️ Tech Stack
- Python  
- TensorFlow / Keras  
- Convolutional Neural Networks (CNN)  
- TensorFlow Lite (TFLite)  
- NumPy, Matplotlib  

---

## 📊 Model Output
- Generates probability scores for each class  
- Softmax activation for normalized output  
- Final prediction based on maximum probability  

---

## 📦 Deployment
- Converted trained model to TensorFlow Lite  
- Suitable for Android, IoT, Edge, and Web platforms  

---

## 📁 Project Files
